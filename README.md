# Student Record Management System in C

A menu-driven Student Record Management System developed in C as a part of my journey towards becoming an Embedded Systems Engineer.

This project focuses on building strong foundations in C programming, memory handling concepts, structured data organization, and problem-solving skills that are essential for embedded software development.

## 🚀 Project Overview

The Student Record Management System allows users to manage student information through a command-line interface.

The system stores student details such as:

* Roll Number
* Name
* Marks

and provides operations to add, display, search, update, and delete student records.

## ✨ Features

* Add new student records
* Display all student records
* Search student by roll number
* Update existing student information
* Delete student records
* Menu-driven user interface

## ▶️ How to Run

1. Clone the repository

```

```

2. Compile the C program

```
gcc Student-Record-System.c -o student_record_system
```

3. Run the executable

```
./student_record_system
```
